Definição do projeto

Expedição de cristais é uma sessão cooperativa curta: entrar, coletar cristais, superar um obstáculo ou NPC, concluir a meta, receber recompensa e melhorar a ferramenta para a próxima expedição.

Capítulo 11.1

Escopo, documento de design e arquitetura

Antes de programar, transforme uma ideia ampla numa promessa pequena que pode ser testada.

Objetivos, pré-requisitos e vocabulário

Pré-requisitos: módulos 0–10. Você escreverá a promessa, o loop, a definição de pronto, o orçamento e as fronteiras de confiança; então montará a árvore mínima do projeto.

A promessa em uma frase

Escreva: “Em sessões de 60–90 segundos, até quatro jogadores coletam cristais, evitam um guardião simples, entregam a meta e usam moedas para melhorar uma ferramenta.” Essa frase define público, duração, ação, risco, recompensa e progressão. Teleporte entre places, matchmaking customizado, monetização e Open Cloud são extensões; não bloqueiam a primeira versão.

O loop possui três camadas oficiais: interação minuto a minuto (mover e procurar), ação repetida (coletar e evitar perigo) e motor de progressão (melhorar ferramenta, facilitando a próxima expedição).

Prática guiada — servidor autoritativo

Projeto aberto: ExpedicaoDeCristais de 11.1. Em ServerScriptService → FinalProject, crie Script Main. Os cristais permanecem visíveis para todos; a coleta é individual por rodada.

Main.server.luauScript · game → ServerScriptService → FinalProject → Main · servidor · inicia com a sessão
--!strict
local Players = game:GetService("Players")
local CollectionService = game:GetService("CollectionService")
local ReplicatedStorage = game:GetService("ReplicatedStorage")

local rootFolder = ReplicatedStorage:WaitForChild("FinalProject")
local remotes = rootFolder:WaitForChild("Remotes")
local requestStart = remotes:WaitForChild("RequestStart") :: RemoteEvent
local requestCollect = remotes:WaitForChild("RequestCollect") :: RemoteEvent
local roundState = remotes:WaitForChild("RoundState") :: RemoteEvent
local Config = require(rootFolder.Shared:WaitForChild("ProjectConfig"))
local startConsole = workspace.FinalMap.Lobby:WaitForChild("StartConsole") :: BasePart

type Round = {endsAt: number, value: number, collected: {[Instance]: boolean}}
local rounds: {[Player]: Round} = {}
local lastRequest: {[Player]: number} = {}

local function rootPart(player: Player): BasePart?
	local character = player.Character
	return character and character:FindFirstChild("HumanoidRootPart") :: BasePart?
end

local function near(player: Player, part: BasePart, maximum: number): boolean
	local root = rootPart(player)
	return root ~= nil and (root.Position - part.Position).Magnitude <= maximum
end

local function emit(player: Player, phase: string, value: number, message: string)
	roundState:FireClient(player, {phase = phase, value = value, goal = Config.GOAL_VALUE, message = message})
end

local function finish(player: Player, success: boolean)
	local round = rounds[player]
	if not round then return end
	rounds[player] = nil
	if success then
		local reward = round.value + 10
		local current = player:GetAttribute("SessionCoins")
		if typeof(current) ~= "number" then current = 0 end
		player:SetAttribute("SessionCoins", current + reward)
		emit(player, "Completed", round.value, "Expedição concluída: +" .. reward)
	else
		emit(player, "Failed", round.value, "Tempo encerrado; nenhuma moeda concedida")
	end
end

requestStart.OnServerEvent:Connect(function(player: Player)
	if rounds[player] or not near(player, startConsole, 12) then return end
	local round: Round = {endsAt = workspace:GetServerTimeNow() + Config.ROUND_DURATION, value = 0, collected = {}}
	rounds[player] = round
	emit(player, "Active", 0, "Colete cristais")
	task.delay(Config.ROUND_DURATION, function()
		if rounds[player] == round then finish(player, false) end
	end)
end)

requestCollect.OnServerEvent:Connect(function(player: Player, candidate: unknown)
	local now = os.clock()
	if now - (lastRequest[player] or 0) < Config.REMOTE_COOLDOWN then return end
	lastRequest[player] = now
	if typeof(candidate) ~= "Instance" or not candidate:IsA("BasePart") then return end
	if not CollectionService:HasTag(candidate, "Crystal") then return end
	local round = rounds[player]
	if not round or workspace:GetServerTimeNow() >= round.endsAt then return end
	if round.collected[candidate] or not near(player, candidate, Config.COLLECTION_DISTANCE) then return end
	local crystalId = candidate:GetAttribute("CrystalId")
	local definition = typeof(crystalId) == "string" and Config.CRYSTALS[crystalId] or nil
	if not definition or typeof(definition.value) ~= "number" then return end
	round.collected[candidate] = true
	round.value += definition.value
	emit(player, "Active", round.value, "+" .. definition.value .. " cristal")
	if round.value >= Config.GOAL_VALUE then finish(player, true) end
end)

Players.PlayerRemoving:Connect(function(player)
	rounds[player] = nil
	lastRequest[player] = nil
end)

Decisões: cliente envia intenção e Instance; servidor decide se o objeto é cristal, se a rodada existe, se a distância é possível, se já foi coletado e quanto vale. Só finish concede a recompensa. O atributo SessionCoins é temporário; persistência chega no próximo capítulo.

local ProximityPromptService = game:GetService("ProximityPromptService")
local ReplicatedStorage = game:GetService("ReplicatedStorage")

local gui = script.Parent :: ScreenGui
local status = gui:WaitForChild("Status") :: TextLabel

ProximityPromptService.PromptTriggered:Connect(function(prompt: ProximityPrompt)
	if prompt.Name == "StartPrompt" then
		requestStart:FireServer()
	elseif prompt.Name == "CollectPrompt" then
		requestCollect:FireServer(prompt.Parent)
	end
end)

roundState.OnClientEvent:Connect(function(payload: unknown)
	if typeof(payload) ~= "table" or typeof(payload.phase) ~= "string"
		or typeof(payload.value) ~= "number" or typeof(payload.goal) ~= "number"
		or typeof(payload.message) ~= "string" then return end
	status.Text = payload.message
	progress.Text = string.format("Cristais: %d / %d", payload.value, payload.goal)
end)

Teste: Test → Start com dois clientes. Inicie e colete separadamente. Cada HUD deve ter progresso próprio. No servidor, chame o remote com uma Part sem tag, com string, de longe e várias vezes: nenhum caso cria moeda. Para simular tempo, reduza temporariamente ROUND_DURATION a 8; falha concede zero. Restaure 75. Para reiniciar, Stop/Start; para desfazer, remova Main, LocalScript e prompts sem apagar a árvore planejada.

Erros comuns: todos progridem juntos indica estado global; recompensa dupla indica conclusão chamada sem remover a rodada; “Infinite yield” indica caminho/nome; coleta distante aceita indica validação no cliente; nenhum prompt no touch/gamepad pede revisar propriedades e emulação.

Prática guiada — perfil final

Projeto aberto: cópia de staging. Reutilize o ProfileStore testado no Módulo 7. Em vez de reescrever concorrência, substitua apenas schema e migração pelos blocos abaixo; preserve UpdateAsync, lock, autosave, BindToClose, retry limitado e regra “load falhou → não salvar”.

FinalProfileSchema.luauModuleScript · game → ServerScriptService → FinalProject → Services → FinalProfileSchema · servidor · usado no load/migração
--!strict
export type Profile = {
	schemaVersion: number,
	coins: number,
	toolLevel: number,
	completedExpeditions: number,
	settings: {reduceMotion: boolean},
}

local Schema = {}
local CURRENT_VERSION = 2

function Schema.default(): Profile
	return {schemaVersion = CURRENT_VERSION, coins = 0, toolLevel = 1,
		completedExpeditions = 0, settings = {reduceMotion = false}}
end

function Schema.migrate(raw: any): Profile
	local profile = Schema.default()
	if typeof(raw) ~= "table" then return profile end
	if typeof(raw.coins) == "number" and math.isfinite(raw.coins) then
		profile.coins = math.clamp(math.floor(raw.coins), 0, 1_000_000_000)
	end
	if typeof(raw.toolLevel) == "number" and math.isfinite(raw.toolLevel) then
		profile.toolLevel = math.clamp(math.floor(raw.toolLevel), 1, 3)
	end
	if typeof(raw.completedExpeditions) == "number" and math.isfinite(raw.completedExpeditions) then
		profile.completedExpeditions = math.clamp(math.floor(raw.completedExpeditions), 0, 1_000_000)
	end
	if typeof(raw.settings) == "table" and typeof(raw.settings.reduceMotion) == "boolean" then
		profile.settings.reduceMotion = raw.settings.reduceMotion
	end
	return profile
end

return table.freeze(Schema)
  1. No ProfileStore do Módulo 7, chame Schema.migrate(raw) dentro do claim de UpdateAsync. O dado retornado já é versão 2.
  2. Depois do load seguro, publique atributos ProfileLoaded, Coins, ToolLevel e ReduceMotion. Se load falhar/lock existir, mantenha o jogador em tela neutra e não inicie rodada.
  3. No Main, exija ProfileLoaded == true no início. Troque SessionCoins por método ProfileStore.AddRoundReward(player, reward), que altera a cópia do servidor e atributos; o autosave persiste.
  4. Crie loja de dois upgrades com catálogo do servidor. Use uma única operação: confirme nível/custo, subtraia moedas e aumente nível na mesma função; pedido repetido após subir encontra custo/estado novo e não compra duas vezes.
Não una perfis “no escuro”

Se load falhar, salvar o default apaga progresso. Se outro servidor possui lock válido, espere/recuse a sessão. Teste essas falhas antes de publicar.

Acessibilidade, localização e setting seguro

Em FinalHud, use Scale, constraints, safe insets, texto legível e foco de gamepad. Não comunique estado só por cor; combine cor, ícone e texto. Adicione TextButton ReduceMotion e envie apenas booleano pelo RequestSetting. O servidor valida nome permitido e tipo, atualiza o perfil e atributo.

local Players = game:GetService("Players")

local gui = script.Parent :: ScreenGui
local button = gui:WaitForChild("ReduceMotion") :: TextButton

local function render()

	button.Text = if reduced then "Movimento reduzido: ligado" else "Movimento reduzido: desligado"
	button:SetAttribute("ReducedMotion", reduced)
	-- Controladores de Tween/partículas consultam este atributo e evitam efeitos não essenciais.

Prática guiada — analytics mínimo

Projeto aberto: release candidate de staging. Em ServerScriptService → FinalProject → Services, crie ModuleScript FinalAnalytics. Chame os eventos apenas depois do fato autoritativo.

FinalAnalytics.luauModuleScript · game → ServerScriptService → FinalProject → Services → FinalAnalytics · servidor · chamado pelo fluxo confirmado
--!strict
local AnalyticsService = game:GetService("AnalyticsService")

local FinalAnalytics = {}
local steps: {[Player]: {[number]: boolean}} = {}

function FinalAnalytics.step(player: Player, number: number, name: string)
	steps[player] = steps[player] or {}
	if steps[player][number] then return end
	steps[player][number] = true
	local ok, message = pcall(function()
		AnalyticsService:LogOnboardingFunnelStepEvent(player, number, name)
	end)
	if not ok then warn("[Analytics] funnel:", message) end
end

function FinalAnalytics.reward(player: Player, amount: number, balance: number)
	if amount <= 0 or balance < 0 or not math.isfinite(amount) or not math.isfinite(balance) then return end
	local ok, message = pcall(function()
		AnalyticsService:LogEconomyEvent(player,
			Enum.AnalyticsEconomyFlowType.Source, "Coins", amount, balance,
			Enum.AnalyticsEconomyTransactionType.Gameplay.Name, "ExpeditionComplete")
	end)
	if not ok then warn("[Analytics] economy:", message) end
end

function FinalAnalytics.cleanup(player: Player)
	steps[player] = nil
end

return table.freeze(FinalAnalytics)

Publicação privada e rollback ensaiado

  1. Congelar: nomeie a versão RC-1, registre hash/commit quando houver Git, schema 2, responsáveis e issues conhecidas (devem ser não críticas).
  2. Backup: salve cópia local e confirme Version History. Exporte o documento de design, matriz de testes e changelog.
  3. Publicar: mantenha acesso privado e adicione somente playtesters. Publique todos os places usados; neste escopo mínimo há um.
  4. Smoke test: conta nova e antiga; dois clientes; teclado, gamepad e mobile; load/save/reconexão; rodada completa e timeout; Output sem erro relevante.
  5. Observar: View Events, falhas de DataStore, memória, heartbeat, rejeições e feedback. Logs não incluem perfil completo ou segredo.
  6. Rollback: publique de volta a versão anterior compatível e repita smoke test. Não reverta código que não entende o schema mais novo sem estratégia de compatibilidade.
Rollback de código não apaga dados novos

Version History restaura place, não o banco. Leitores devem tolerar campos desconhecidos; migrações devem ser aditivas ou possuir plano de volta.

Gabarito comentado

Fácil: “adicionado loop de 75 s”, “três IDs validados no servidor”, “schema 2 com reduceMotion”, “HUD testado em três larguras”, “funnel de quatro passos” são verificáveis.

Intermediário: Version History recupera scripts, objetos e configuração do place; não desfaz automaticamente DataStore. O smoke test pós-rollback deve ler schema 2 sem perda.

Desafiador: outra pessoa deve conseguir publicar, observar e reverter usando seus documentos. Se depende de memória do autor, o runbook está incompleto.
