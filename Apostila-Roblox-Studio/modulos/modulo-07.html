Dificuldade 3–4/5 · intermediária avançada

Salve progresso sem transformar uma falha em perda de dados.

Você começará com um perfil em memória, fará a primeira gravação em uma experiência separada e evoluirá para migração, retries limitados, bloqueio de sessão, economia idempotente e uma pequena vertical slice de simulador.

  • Projetos: concluir Salvamento de progresso e construir Simulador enxuto

Persistência amplia consequências

Um erro em memória termina com o servidor. Um erro persistido volta na próxima sessão. Por isso, cada escrita terá condição, evidência e caminho de recuperação.

ProfileSchema.luauModuleScript · ServerScriptService/Dados · servidor · no primeiro require
--!strict
export type Profile = {
	schemaVersion: number,
	currencies: {coins: number},
	progress: {checkpointId: string},
	inventory: {[string]: number},
	claimedRewards: {[string]: boolean},
}

local CURRENT_VERSION = 2
local ProfileSchema = {}

local function safeInteger(value: any, fallback: number, maximum: number): number
	if typeof(value) ~= "number" or not math.isfinite(value) then
		return fallback
	end
	return math.clamp(math.floor(value), 0, maximum)
end

function ProfileSchema.new(): Profile
	return {
		schemaVersion = CURRENT_VERSION,
		currencies = {coins = 0},
		progress = {checkpointId = "inicio"},
		inventory = {},
		claimedRewards = {},
	}
end

function ProfileSchema.migrate(raw: any): Profile
	local profile = ProfileSchema.new()
	if typeof(raw) ~= "table" then
		return profile
	end

	-- Formato antigo usado somente pelo laboratório.
	if raw.version == 1 then
		profile.currencies.coins = safeInteger(raw.coins, 0, 1_000_000_000)
		profile.progress.checkpointId = `checkpoint_{safeInteger(raw.checkpoint, 0, 999)}`
		return profile
	end

	if raw.schemaVersion == CURRENT_VERSION then
		local currencies = raw.currencies
		if typeof(currencies) == "table" then
			profile.currencies.coins = safeInteger(currencies.coins, 0, 1_000_000_000)
		end
		local progress = raw.progress
		if typeof(progress) == "table" and typeof(progress.checkpointId) == "string" then
			profile.progress.checkpointId = string.sub(progress.checkpointId, 1, 50)
		end
		for itemId, amount in (raw.inventory or {}) do
			if typeof(itemId) == "string" and #itemId <= 50 then
				profile.inventory[itemId] = safeInteger(amount, 0, 10_000)
			end
		end
		for rewardId, claimed in (raw.claimedRewards or {}) do
			if typeof(rewardId) == "string" and claimed == true then
				profile.claimedRewards[rewardId] = true
			end
		end
	end

	return profile
end

return table.freeze(ProfileSchema)

Capítulo 7.2

DataStore básico e ambiente de teste seguro

Faça a primeira leitura e escrita sem tocar nos dados de produção.

Objetivos e novas palavras

Pré-requisitos: 7.1, 2.8 e 6.3. Você configurará uma experiência separada, usará GetAsync e SetAsync, aplicará pcall somente à chamada externa, observará budget e impedirá save após falha de load.

Data store
Armazenamento persistente compartilhado pelos places da experiência.
Chave
String única que identifica um valor armazenado.
Budget
Quantidade de solicitações que o servidor pode fazer naquele momento.
Throttling
Atraso ou recusa causada por excesso de solicitações.
Falha externa
Problema fora da lógica local, como conectividade ou serviço indisponível.
Resultado inconclusivo
Resposta falha que não prova sozinha qual estado final ficou gravado.

Escolha a operação pelo conflito

OperaçãoServe paraRisco/limite
GetAsyncler uma chavepode retornar cache e falhar
SetAsyncsubstituição simples e controladadois servidores podem sobrescrever um ao outro
UpdateAsyncler a versão atual e decidir a escrita atomicamentemais custoso; callback não pode fazer yield
IncrementAsyncincrementar um inteiro isoladonão atualiza um perfil composto

O pcall captura o erro lançado pela operação de rede e devolve sucesso/resultado. Ele não valida dados e não deve envolver todo o sistema. Uma escrita que falhou pode ter estado final desconhecido; operações importantes precisam ser idempotentes e verificáveis.

Nunca teste contra produção

Studio acessa os mesmos data stores da experiência publicada. Crie uma experiência de teste separada e habilite API Services somente nela. O nome ProfileLab_v1 não torna seguro usar o mesmo universo público.

BasicProfileStore.luauModuleScript · ServerScriptService/Dados · servidor · chamadas sob demanda
--!strict
local DataStoreService = game:GetService("DataStoreService")
local ProfileSchema = require(script.Parent.ProfileSchema)

local store = DataStoreService:GetDataStore("ProfileLab_v1")
local BasicProfileStore = {}
local SIMULATE_FAILURE = false

local function keyFor(userId: number): string
	return `Player_{userId}`
end

function BasicProfileStore.loadAsync(userId: number)
	local success, result = pcall(function()
		if SIMULATE_FAILURE then
			error("Falha externa simulada para a aula")
		end
		return store:GetAsync(keyFor(userId))
	end)
	if not success then
		return false, nil, tostring(result)
	end
	return true, ProfileSchema.migrate(result), nil
end

function BasicProfileStore.saveAsync(userId: number, profile: ProfileSchema.Profile)
	local success, result = pcall(function()
		return store:SetAsync(keyFor(userId), profile)
	end)
	if not success then
		return false, tostring(result)
	end
	return true, nil
end

return table.freeze(BasicProfileStore)

A palavra Async lembra que a função pode ceder a execução. Somente GetAsync/SetAsync ficam dentro do pcall; erros em migração continuam visíveis.

Capítulo 7.3

Salvamento robusto, migração, retries e sessão

Proteja a versão mais nova contra falha, concorrência e entrada em outro servidor.

Objetivos e vocabulário

Pré-requisitos: 7.2 e 6.3. Você implementará retry com backoff limitado, UpdateAsync idempotente, session ownership em metadata, autosave, save final e observabilidade. Também provará que load falho e lock perdido não escrevem.

Concorrência
Duas execuções tentando alterar o mesmo estado em períodos sobrepostos.
Backoff
Espera crescente entre tentativas para não agravar uma falha.
Session lock
Marca persistente que reserva um perfil para um servidor.
Autosave
Gravação periódica que reduz a perda se o save final falhar.
Metadata
Informação associada à chave sem fazer parte do valor do perfil.
Dirty
Estado em memória alterado desde a última gravação confirmada.

O problema que “salvar ao sair” não resolve

O jogador pode sair do servidor A e entrar no B antes do save terminar. Sem lock, B carrega a versão antiga e depois pode apagar o avanço de A. O lock é adquirido atomicamente durante UpdateAsync, renovado pelo autosave e liberado no save final.

Load + lock→Sessão em memória→Autosave + renova→Save final + libera

Retries da mesma chave precisam permanecer em ordem. A operação abaixo é idempotente: repetir o load pelo mesmo JobId ou gravar o mesmo snapshot não duplica recompensa. Há no máximo três tentativas; falha persistente vira estado observável.

Base educacional auditável

Este módulo implementa as garantias estudadas, mas sistemas com trocas, compras e grande escala exigem testes de carga e auditoria. A própria amostra oficial alerta que código de referência não deve ser usado sem testes extensos.

RobustProfileStore.luauModuleScript · ServerScriptService/Dados · servidor · chamadas serializadas por jogador
--!strict
local DataStoreService = game:GetService("DataStoreService")
local HttpService = game:GetService("HttpService")
local ProfileSchema = require(script.Parent.ProfileSchema)

local store = DataStoreService:GetDataStore("Profiles_v2")
local JOB_ID = if game.JobId ~= "" then game.JobId else `studio_{HttpService:GenerateGUID(false)}`
local LOCK_SECONDS = 120
local MAX_ATTEMPTS = 3
local RobustProfileStore = {}

local function keyFor(userId: number): string
	return `Player_{userId}`
end

local function retry(operationName: string, operation: () -> any)
	local lastMessage = "falha desconhecida"
	for attempt = 1, MAX_ATTEMPTS do
		local success, result = pcall(operation)
		if success then
			return true, result, nil
		end
		lastMessage = tostring(result)
		warn(`[DATA] op={operationName} tentativa={attempt} erro={lastMessage}`)
		if attempt < MAX_ATTEMPTS then
			task.wait(2 ^ (attempt - 1) + math.random() * 0.25)
		end
	end
	return false, nil, lastMessage
end

function RobustProfileStore.loadAsync(userId: number)
	local blockedByOtherSession = false
	local now = os.time()
	local success, result, message = retry("load", function()
		return store:UpdateAsync(keyFor(userId), function(current, keyInfo)
			local metadata = if keyInfo then keyInfo:GetMetadata() else {}
			local lockId = metadata.LockId
			local expiresAt = metadata.LockExpiresAt or 0
			if lockId and lockId ~= JOB_ID and expiresAt > now then
				blockedByOtherSession = true
				return nil
			end
			metadata.LockId = JOB_ID
			metadata.LockExpiresAt = now + LOCK_SECONDS
			return ProfileSchema.migrate(current), {userId}, metadata
		end)
	end)
	if not success then
		return false, nil, message
	end
	if blockedByOtherSession or result == nil then
		return false, nil, "Perfil ocupado por outra sessão"
	end
	return true, ProfileSchema.migrate(result), nil
end

function RobustProfileStore.saveAsync(
	userId: number,
	profile: ProfileSchema.Profile,
	releaseLock: boolean
)
	-- migrate cria um snapshot serializável e separado do estado vivo.
	local snapshot = ProfileSchema.migrate(profile)
	local lostLock = false
	local success, _, message = retry("save", function()
		return store:UpdateAsync(keyFor(userId), function(_current, keyInfo)
			local metadata = if keyInfo then keyInfo:GetMetadata() else {}
			if metadata.LockId ~= JOB_ID then
				lostLock = true
				return nil
			end
			if releaseLock then
				metadata.LockId = nil
				metadata.LockExpiresAt = nil
			else
				metadata.LockExpiresAt = os.time() + LOCK_SECONDS
			end
			return snapshot, {userId}, metadata
		end)
	end)
	if lostLock then
		return false, "Lock perdido; escrita cancelada"
	end
	return success, message
end

return table.freeze(RobustProfileStore)

O callback de UpdateAsync não contém task.wait nem outra função que ceda. O backoff acontece fora dele. Metadata existente é preservada e o perfil não armazena o JobId como progresso.

ProfileBootstrap.server.luauScript · ServerScriptService/Dados · servidor · entrada, autosave, saída e fechamento
--!strict
local Players = game:GetService("Players")
local RobustProfileStore = require(script.Parent.RobustProfileStore)

local sessions = {}
local saving = {}

local function saveOne(player: Player, releaseLock: boolean): boolean
	local profile = sessions[player]
	if not profile or player:GetAttribute("DataReady") ~= true then
		return false
	end
	if saving[player] then
		if not releaseLock then
			return false -- autosave: o anterior já protege esta sessão
		end
		local deadline = os.clock() + 10
		while saving[player] and os.clock() < deadline do
			task.wait(0.1)
		end
		if saving[player] then
			return false -- encerramento não pode esperar indefinidamente
		end
	end
	saving[player] = true
	local success, message = RobustProfileStore.saveAsync(
		player.UserId,
		profile,
		releaseLock
	)
	saving[player] = nil
	if not success then
		warn(`[SAVE] user={player.UserId} erro={message}`)
	end
	return success
end

Players.PlayerAdded:Connect(function(player)
	player:SetAttribute("DataReady", false)
	local loaded, profile, message = RobustProfileStore.loadAsync(player.UserId)
	if not loaded or not profile then
		warn(`[LOAD] user={player.UserId} erro={message}`)
		return -- perfil padrão nunca entra em sessions
	end
	sessions[player] = profile
	player:SetAttribute("Coins", profile.currencies.coins)
	player:SetAttribute("CheckpointId", profile.progress.checkpointId)
	player:SetAttribute("DataReady", true)
end)

Players.PlayerRemoving:Connect(function(player)
	local deadline = os.clock() + 10
	while saving[player] and os.clock() < deadline do
		task.wait(0.1)
	end
	saveOne(player, true)
	sessions[player] = nil
end)

task.spawn(function()
	while true do
		task.wait(60)
		for _, player in Players:GetPlayers() do
			task.spawn(function()
				task.wait((player.UserId % 10) / 10)
				saveOne(player, false)
			end)
		end
	end
end)

game:BindToClose(function()
	local remaining = 0
	for _, player in Players:GetPlayers() do
		remaining += 1
		task.spawn(function()
			saveOne(player, true)
			remaining -= 1
		end)
	end
	local deadline = os.clock() + 25
	while remaining > 0 and os.clock() < deadline do
		task.wait(0.1)
	end
end)

--!strict
local V2 = require(script.Parent.ProfileSchemaV2)

export type Profile = {
	schemaVersion: number,
	currencies: {coins: number},
	progress: {checkpointId: string},
	inventory: {[string]: number},
	claimedRewards: {[string]: boolean},
	simulator: {
		bagOre: number,
		capacity: number,
		pickaxeLevel: number,
		areaLevel: number,
		rebirths: number,
		oresMined: number,
	},
}

local ProfileSchema = {}

local function safeInteger(value: any, fallback: number, maximum: number): number
	if typeof(value) ~= "number" or not math.isfinite(value) then
		return fallback
	end
	return math.clamp(math.floor(value), 0, maximum)
end

local function baseFrom(raw: any): V2.Profile
	if typeof(raw) == "table" and raw.schemaVersion == 3 then
		return V2.migrate({
			schemaVersion = 2,
			currencies = raw.currencies,
			progress = raw.progress,
			inventory = raw.inventory,
			claimedRewards = raw.claimedRewards,
		})
	end
	return V2.migrate(raw)
end

function ProfileSchema.new(): Profile
	return ProfileSchema.migrate(nil)
end

function ProfileSchema.migrate(raw: any): Profile
	local base = baseFrom(raw)
	local profile: Profile = {
		schemaVersion = 3,
		currencies = base.currencies,
		progress = base.progress,
		inventory = base.inventory,
		claimedRewards = base.claimedRewards,
		simulator = {
			bagOre = 0,
			capacity = 10,
			pickaxeLevel = 1,
			areaLevel = 1,
			rebirths = 0,
			oresMined = 0,
		},
	}
	if typeof(raw) == "table" and raw.schemaVersion == 3
		and typeof(raw.simulator) == "table" then
		local simulator = raw.simulator
		profile.simulator.bagOre = safeInteger(simulator.bagOre, 0, 100_000)
		profile.simulator.capacity = math.max(10, safeInteger(simulator.capacity, 10, 100_000))
		profile.simulator.pickaxeLevel = math.max(1, safeInteger(simulator.pickaxeLevel, 1, 100))
		profile.simulator.areaLevel = math.max(1, safeInteger(simulator.areaLevel, 1, 20))
		profile.simulator.rebirths = safeInteger(simulator.rebirths, 0, 1_000)
		profile.simulator.oresMined = safeInteger(simulator.oresMined, 0, 1_000_000_000)
		profile.simulator.bagOre = math.min(
			profile.simulator.bagOre,
			profile.simulator.capacity
		)
	end
	return profile
end

return table.freeze(ProfileSchema)

RewardRules.luauModuleScript · ServerScriptService/Dados · servidor · chamado dentro da alteração de perfil
--!strict
local ProfileSchema = require(script.Parent.ProfileSchema)

export type Result = {ok: boolean, message: string}

type QuestDefinition = {required: number, rewardCoins: number}

local MAX_COINS = 1_000_000_000
local QUESTS: {[string]: QuestDefinition} = {
	primeiros_10_minerios = {required = 10, rewardCoins = 75},
}
local RewardRules = {}

function RewardRules.tryClaim(
	profile: ProfileSchema.Profile,
	rewardId: string
): Result
	local quest = QUESTS[rewardId]
	if not quest then
		return {ok = false, message = "Missão desconhecida."}
	end
	if profile.claimedRewards[rewardId] then
		return {ok = false, message = "Recompensa já concedida."}
	end
	if profile.simulator.oresMined < quest.required then
		return {ok = false, message = "Objetivo ainda incompleto."}
	end
	if profile.currencies.coins > MAX_COINS - quest.rewardCoins then
		return {ok = false, message = "Limite de moedas alcançado."}
	end

	-- Sem yield: marca e recompensa formam uma única alteração em memória.
	profile.claimedRewards[rewardId] = true
	profile.currencies.coins += quest.rewardCoins
	return {ok = true, message = "Recompensa concedida uma vez."}
end

return table.freeze(RewardRules)

ProfileState.luauModuleScript · ServerScriptService/Dados · servidor · estado vivo da sessão
--!strict
local ProfileSchema = require(script.Parent.ProfileSchema)

local profiles: {[Player]: ProfileSchema.Profile} = {}
local ProfileState = {}

local function sync(player: Player, profile: ProfileSchema.Profile)
	player:SetAttribute("Coins", profile.currencies.coins)
	player:SetAttribute("BagOre", profile.simulator.bagOre)
	player:SetAttribute("Capacity", profile.simulator.capacity)
	player:SetAttribute("PickaxeLevel", profile.simulator.pickaxeLevel)
	player:SetAttribute("AreaLevel", profile.simulator.areaLevel)
	player:SetAttribute("Rebirths", profile.simulator.rebirths)
end

function ProfileState.attach(player: Player, profile: ProfileSchema.Profile)
	profiles[player] = profile
	sync(player, profile)
	player:SetAttribute("DataReady", true)
end

function ProfileState.get(player: Player): ProfileSchema.Profile?
	return profiles[player]
end

function ProfileState.update(
	player: Player,
	mutator: (ProfileSchema.Profile) -> ()
): boolean
	local profile = profiles[player]
	if not profile or player:GetAttribute("DataReady") ~= true then
		return false
	end
	mutator(profile) -- sem pcall: erro de programação deve aparecer
	sync(player, profile)
	return true
end

function ProfileState.detach(player: Player)
	profiles[player] = nil
	player:SetAttribute("DataReady", false)
end

return table.freeze(ProfileState)

SimulatorService.luauModuleScript · ServerScriptService/Simulator · servidor · chamado pelo bootstrap
--!strict
local ProfileState = require(script.Parent.Parent.Dados.ProfileState)
local RewardRules = require(script.Parent.Parent.Dados.RewardRules)
local Config = require(script.Parent.SimulatorConfig)

local SimulatorService = {}
local lastMineAt: {[Player]: number} = {}

local function isNear(player: Player, part: BasePart, maximum: number): boolean
	local character = player.Character
	local root = character and character:FindFirstChild("HumanoidRootPart")
	local humanoid = character and character:FindFirstChildOfClass("Humanoid")
	return root ~= nil and root:IsA("BasePart")
		and humanoid ~= nil and humanoid.Health > 0
		and (root.Position - part.Position).Magnitude <= maximum
end

function SimulatorService.mine(player: Player, target: any): string
	if typeof(target) ~= "Instance" or not target:IsA("BasePart") then
		return "Alvo inválido."
	end
	local ores = workspace.Simulator.Ores
	if not target:IsDescendantOf(ores) or not isNear(player, target, Config.MineDistance) then
		return "Minério fora do contexto permitido."
	end
	local character = player.Character
	local tool = character and character:FindFirstChild("Picareta")
	if not tool or not tool:IsA("Tool") then
		return "Equipe a picareta."
	end
	local now = os.clock()
	if now - (lastMineAt[player] or 0) < Config.MineCooldown then
		return "Aguarde a picareta."
	end
	lastMineAt[player] = now

	local oreId = target:GetAttribute("OreId")
	if typeof(oreId) ~= "string" then
		return "Minério sem ID válido."
	end
	local ore = Config.Ores[oreId]
	if not ore then
		return "Minério desconhecido."
	end

	local message = "Perfil indisponível."
	ProfileState.update(player, function(profile)
		if profile.simulator.areaLevel < ore.area then
			message = "Área ainda bloqueada."
			return
		end
		local space = profile.simulator.capacity - profile.simulator.bagOre
		local amount = math.min(ore.baseYield + profile.simulator.pickaxeLevel - 1, space)
		if amount <= 0 then
			message = "Mochila cheia."
			return
		end
		profile.simulator.bagOre += amount
		profile.simulator.oresMined += amount
		RewardRules.tryClaim(profile, "primeiros_10_minerios")
		message = `+{amount} minério(s).`
	end)
	return message
end

function SimulatorService.sell(player: Player, point: BasePart): string
	if not isNear(player, point, 12) then return "Venda fora de alcance." end
	local message = "Perfil indisponível."
	ProfileState.update(player, function(profile)
		local amount = profile.simulator.bagOre
		if amount <= 0 then message = "Mochila vazia." return end
		local earned = amount * 3 -- preço-base conservador da vertical slice
		if profile.currencies.coins > Config.MaxCoins - earned then
			message = "Limite de moedas alcançado." return
		end
		profile.simulator.bagOre = 0
		profile.currencies.coins += earned
		message = `Venda concluída: +{earned} moedas.`
	end)
	return message
end

function SimulatorService.upgrade(player: Player, point: BasePart): string
	if not isNear(player, point, 12) then return "Upgrade fora de alcance." end
	local message = "Perfil indisponível."
	ProfileState.update(player, function(profile)
		local level = profile.simulator.pickaxeLevel
		local cost = level * 100
		if level >= 100 then message = "Nível máximo." return end
		if profile.currencies.coins < cost then message = "Moedas insuficientes." return end
		profile.currencies.coins -= cost
		profile.simulator.pickaxeLevel += 1
		message = `Picareta nível {level + 1}.`
	end)
	return message
end

function SimulatorService.unlockArea(player: Player, point: BasePart): string
	if not isNear(player, point, 12) then return "Área fora de alcance." end
	local message = "Perfil indisponível."
	ProfileState.update(player, function(profile)
		if profile.simulator.areaLevel >= 2 then message = "Área já liberada." return end
		if profile.currencies.coins < Config.AreaTwoCost then message = "Moedas insuficientes." return end
		profile.currencies.coins -= Config.AreaTwoCost
		profile.simulator.areaLevel = 2
		message = "Área de cristal liberada."
	end)
	return message
end

function SimulatorService.rebirth(player: Player, point: BasePart): string
	if not isNear(player, point, 12) then return "Rebirth fora de alcance." end
	local message = "Perfil indisponível."
	ProfileState.update(player, function(profile)
		if profile.currencies.coins < Config.RebirthCost then message = "Requisito incompleto." return end
		profile.currencies.coins = 0
		profile.simulator.bagOre = 0
		profile.simulator.capacity = 10
		profile.simulator.pickaxeLevel = 1
		profile.simulator.areaLevel = 1
		profile.simulator.rebirths += 1
		message = "Rebirth concluído."
	end)
	return message
end

return table.freeze(SimulatorService)

Não há yield dentro de ProfileState.update. Portanto, cada transação em memória termina antes de outra callback alterar o mesmo perfil. O autosave grava o snapshot depois.

	local camera = workspace.CurrentCamera

	local center = camera.ViewportSize / 2
	local ray = camera:ViewportPointToRay(center.X, center.Y)

end)

Avaliação de domínio · não contabilizada como capítulo

Prove integridade antes de avançar

Avance somente se conseguir explicar e demonstrar os oito itens sem consultar o gabarito.

  1. Migre um perfil v1 para v3 e mostre os valores padrão novos.
  2. Explique por que leaderstats não é a fonte da verdade.
  3. Mostre no Output que uma falha de load bloqueia o save.
  4. Compare SetAsync, UpdateAsync e IncrementAsync com um cenário adequado para cada.
  5. Faça três retries terminarem e identifique o backoff.
  6. Mostre que outro servidor não carrega um lock ativo e que o antigo não salva após perder o lock.
  7. Chame a missão duas vezes e prove que moedas não duplicam.
  8. Execute a matriz hostil do simulador e reabra a sessão.
Critério e encaminhamento

Domínio: todas as evidências são reproduzíveis nos modos indicados, sem editar manualmente o dado para fabricar sucesso. Se load falho salvar, lock perdido gravar ou recompensa repetir, volte a 7.2–7.4 antes de seguir.

Pronto para o Módulo 8: perfil íntegro nos cenários normal, concorrente e de falha; vertical slice funciona em teclado, gamepad e touch; nenhum resultado importante depende do cliente.
